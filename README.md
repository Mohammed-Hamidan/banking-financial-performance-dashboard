# Banking Financial Performance Dashboard | Power BI

## Project Overview

A financial performance dashboard developed using Microsoft Power BI to analyze and compare banking performance across 2025 and 2026.

The dashboard provides insights into revenue, expenses, profitability, and financial performance trends through interactive visualizations and DAX calculations.

## Key Features

- Revenue and expense analysis
- Net income monitoring
- Foreign exchange revaluation analysis
- Cost-to-Income Ratio
- Profit Margin
- Year-over-Year (YoY) comparisons
- Year-to-Date (YTD) calculations
- Interactive filters for years, months, and branches

## Tools & Technologies

- **Power BI** — Dashboard development and visualization
- **DAX** — Financial measures and time intelligence
- **Power Query** — Data cleaning and transformation
- **Data Modeling** — Relationships and date dimensions
- **Figma** — Dashboard UI design

## Analytical Approach

The dashboard uses DAX measures to calculate financial KPIs, including YTD totals and previous-year comparisons.

A date dimension enables time-based analysis, while interactive slicers allow users to explore performance across different periods and branches.
